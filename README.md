# Killian Haverty – portfolio

- **Edit content:** sign in at https://app.pagescms.org with GitHub and open this repo.
  The site rebuilds automatically about a minute after each save.
- **Content files:** `_data/*.yml` (Pages CMS edits these for you).
- **Layout & design:** `index.html`, `interests.html`, `site.css`, `home.css`, `interests.css`.
- **Editor setup:** `.pages.yml`.
- This site needs Jekyll, so don't add a `.nojekyll` file.
